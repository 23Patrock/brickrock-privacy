2. Account & Online Features

BrickRock can be played without an account. An account is required for online features such as public leaderboards, Friends, Collection purchases, Supporter access, and cross-device persistence.

Friends are added using Friend Codes. BrickRock does not have a global user search or chat.

3. Offline Play

Full runs can be played without an internet connection. Completed runs are cached and synchronized when a connection becomes available again. Live leaderboards and the Collection require an internet connection.

4. Supporter Pack

The BrickRock Supporter Pack is a one-time in-app purchase, not a subscription. It automatically unlocks double Run Coins and the cosmetic REFRACT set. It provides no gameplay advantage.

If you have already bought the Supporter Pack and it is not unlocked after a reinstall or on another device, use “RESTORE PURCHASES” in the Collection. Because Supporter status belongs to your account, you need to be signed in to that same account.
