# brickrock-privacy

Öffentliche Datenschutzerklärung für die Mobile-App **BrickRock**.

Dieses Repository enthält ausschliesslich die statische Webseite, die über
GitHub Pages ausgeliefert und in der Google Play Console als
Datenschutzerklärung hinterlegt wird.

**Veröffentlicht unter:** https://23patrock.github.io/brickrock-privacy/

## Inhalt

| Datei | Zweck |
| --- | --- |
| `index.html` | Die Datenschutzerklärung. Vollständig eigenständig: eigenes CSS, keine externen Schriftarten, kein JavaScript, keine Cookies, keine Tracker. |
| `.nojekyll` | Schaltet die Jekyll-Verarbeitung von GitHub Pages ab; die Datei wird unverändert ausgeliefert. |
| `README.md` | Diese Datei. |

## Bewusst nicht enthalten

Der Quellcode von BrickRock liegt in einem **privaten** Repository und bleibt
dort. In diesem öffentlichen Repository befinden sich keine Zugangsdaten,
Schlüssel, Zertifikate, `.env`-Dateien, Firebase-Konfigurationen und keine
Teile des Anwendungscodes.

## Änderungen

Wird die Datenschutzerklärung angepasst, ist das Datum unter „Stand“ in
`index.html` mitzuführen – an zwei Stellen: im Kopf der Seite und in der
Fusszeile.
